Beacon widget in a plain HTML page

No React, no build step, no framework. This page is static HTML that loads one script and calls BeaconCCA.mount(). The card below reads live Sepolia state through @hammerock/cca-sdk. 

<div id="beacon"></div>
<script src="/beacon-widget.js"></script>
<script>
  BeaconCCA.mount('#beacon', {
    auction: '0x145A9163d5a89fe843955b1D337F75d46088E156',
    chainId: 11155111,
    rpcUrl: 'https://ethereum-sepolia-rpc.publicnode.com'
  });
</script>
